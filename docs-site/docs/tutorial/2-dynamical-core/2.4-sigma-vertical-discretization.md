# 2.4 σ Vertical Discretization { #_1 }

This note continues from [2.1 Governing Equations](<2.1-governing-equations.md>) with the same governing equations and notation, and keeps the original equation numbers.

It describes how the vertical σ grid is built and how the continuous column integrals and vertical flux divergences become the discrete sums and interface differences used by the dynamical core. Step 2 of [2.2 Ten-Step Algorithm](<2.2-ten-step-algorithm.md>) shows how these discrete operators enter the grid-point nonlinear dynamics.


## 1. Staggered grid

Let there be \(L\) full levels. The bottom interface of layer \(k\) is
\(\sigma_{k+1/2}\), and its thickness is

$$
\Delta\sigma_k
=\sigma_{k+1/2}-\sigma_{k-1/2},
\tag{2.4.1}
$$

with

$$
\sigma_{1/2}=0,\qquad \sigma_{L+1/2}=1.
$$

The full-level variables \(T,D,\zeta,U,V,\chi\) sit at layer centers, while \(\dot\sigma\) sits on the interfaces:

![Staggered sigma grid showing full levels and interfaces](<../assets/images/sigma_coordinates.png>)

*Figure 2.4.1 | Staggered σ grid: full-level state variables are stored at layer centers, and the vertical mass flux is stored at the L+1 interfaces.*


## 2. Constructing the σ levels

When the vertical grid is built, the first thing to keep apart is the mathematical level numbering and the C array indexing. Mathematically there are \(L\) full levels and \(L+1\) interfaces:

$$
\underbrace{\sigma_{1/2}}_{0},\
\sigma_{3/2},\
\sigma_{5/2},\ldots,\
\underbrace{\sigma_{L+1/2}}_{1}.
$$

The \(k\)-th full level lies between \(\sigma_{k-1/2}\) and \(\sigma_{k+1/2}\), where
\(k=1,\ldots,L\). The program does not need to store the model-top interface, which is always 0; instead, the length-\(L\) array
`sigma_half[0..L-1]` stores the bottom interface of every layer:

$$
\mathtt{sigma\_half}[k-1]=\sigma_{k+1/2},
\qquad k=1,\ldots,L.
$$

C arrays start at 0 while mathematical level numbering starts at 1; if this mapping is not stated explicitly first, it is easy to introduce a spurious extra 1 into a formula.

### 2.1 User-prescribed interfaces

When `sigma_mode = -1`, the code reads the \(L\) bottom interfaces
\(\sigma_{3/2},\ldots,\sigma_{L-1/2}\) directly. For the grid to be valid, the input must satisfy

$$
0<\sigma_{3/2}<\sigma_{5/2}<\cdots
<\sigma_{L+1/2}=1.
$$

The model top \(\sigma_{1/2}=0\) is an implicit boundary and is not included in the input array. The current constructor uses the values supplied by the caller as they are, so the caller must guarantee that they increase strictly and end at 1.

### 2.2 Uniform σ levels

To give every layer the same σ thickness, divide the interval \([0,1]\) into \(L\) equal parts. To avoid confusion with the full-level numbering \(k=1,\ldots,L\), number the interfaces by \(r=0,\ldots,L\):

$$
\sigma_{r+1/2}=\frac{r}{L},
\qquad r=0,1,\ldots,L.
\tag{2.4.2}
$$

Substituting adjacent interfaces into (2.4.1) gives immediately

$$
\Delta\sigma_k
=\sigma_{k+1/2}-\sigma_{k-1/2}
=\frac{1}{L},
\qquad k=1,\ldots,L.
$$

Equation (2.4.2) also passes the boundary check directly: \(r=0\) gives
\(\sigma_{1/2}=0\), and \(r=L\) gives \(\sigma_{L+1/2}=1\). For example, with \(L=4\) the interfaces are \(0,1/4,1/2,3/4,1\), and all four layer thicknesses equal \(1/4\).

When the loop variable in the code is written \(\ell=0,\ldots,L-1\), the same relation becomes

$$
\mathtt{sigma\_half}[\ell]
=\frac{\ell+1}{L}
=\sigma_{\ell+3/2}.
$$

So the source expression `(level + 1) / level_count` is correct.

### 2.3 Polynomially stretched levels

A stretched grid first takes equally spaced points in an auxiliary coordinate \(s\in[0,1]\) and then maps them to σ through a polynomial \(f(s)\):

$$
s_r=\frac{r}{L},
\qquad
\sigma_{r+1/2}=f(s_r),
\qquad
f(s)=\frac34s+\frac74s^3-\frac32s^4,
\qquad r=0,1,\ldots,L.
\tag{2.4.3}
$$

This polynomial satisfies

$$
f(0)=0,
\qquad
f(1)=1,
\qquad
f'(s)=\frac34(1-s)(8s^2+s+1)\ge0
\quad (0\le s\le1).
$$

It therefore preserves the top and bottom boundaries and guarantees that the interface order cannot reverse. Since \(f'(s)\) is larger in the middle and tends to 0 near the surface, a stretched grid normally gives thinner layers at the model top and near the ground, and thicker layers in the middle atmosphere, compared with a uniform grid. This stretching polynomial is the choice made in PlaSiC
(Fraedrich et al., 2005).

With \(L=5\) as an example:

| \(r\) | \(s_r=r/L\) | \(\sigma_{r+1/2}=f(s_r)\) | Adjacent-interface spacing |
|---:|---:|---:|---:|
| 0 | 0.0 | 0.0000 | — |
| 1 | 0.2 | 0.1616 | 0.1616 |
| 2 | 0.4 | 0.3736 | 0.2120 |
| 3 | 0.6 | 0.6336 | 0.2600 |
| 4 | 0.8 | 0.8816 | 0.2480 |
| 5 | 1.0 | 1.0000 | 0.1184 |

The top and bottom layers are thinner than the uniform value \(0.2\), while the middle layers are thicker.

### 2.4 Full-level positions and thicknesses from the interfaces

Whichever way the interfaces are obtained — user input, a uniform grid, or a stretched grid — every layer uses the same diagnostic relations:

$$
\Delta\sigma_k
=\sigma_{k+1/2}-\sigma_{k-1/2},
\qquad
\sigma_k=\frac12
\left(\sigma_{k-1/2}+\sigma_{k+1/2}\right),
\qquad k=1,\ldots,L.
\tag{2.4.4}
$$

Here \(\sigma_k\) is the arithmetic midpoint of the two interfaces in σ. In code this corresponds to `sigma_thickness[k-1]`, `sigma_full[k-1]`, and the factor \(1/(2\Delta\sigma_k)\) used later by the vertical flux differences. After the grid has been constructed, at least the following should be checked:

$$
\Delta\sigma_k>0,
\qquad
\sum_{k=1}^{L}\Delta\sigma_k=1,
\qquad
0<\sigma_1<\cdots<\sigma_L<1.
$$

## 3. How continuous integrals become discrete sums

Column integrals use the layer thickness as the integration weight:

$$
\int_0^1A\,d\sigma
\approx\sum_{j=1}^{L}\Delta\sigma_jA_j.
\tag{2.4.5}
$$

Here \(A\) is the mass flux divergence of (2.1.13), i.e. the same quantity that appears in the column mass equation (2.1.5).

On the staggered grid, \(\dot\sigma_{r+1/2}\) becomes

$$
\dot\sigma_{r+1/2}
=\sigma_{r+1/2}
\sum_{j=1}^{L}\Delta\sigma_jA_j
-\sum_{j=1}^{r}\Delta\sigma_jA_j,
\qquad r=0,\ldots,L.
\tag{2.4.6}
$$

At \(r=0\) the second sum is empty and the prefactor is \(\sigma_{1/2}=0\), so \(\dot\sigma_{1/2}=0\); at \(r=L\) the two sums are identical, so \(\dot\sigma_{L+1/2}=0\). The no-penetration conditions at the top and bottom are therefore not an extra patch: they are part of the discretized continuity equation.

The same cumulative sums also provide the pressure vertical velocity \(\omega/p\) of (2.1.15); in the code it is assembled with the vertical integration matrix \(C\) of [2.5 Semi-Implicit Gravity-Wave Solve](<2.5-semi-implicit-gravity-wave-solver.md>), whose discrete form is listed in the Step 2 table of [2.2 Ten-Step Algorithm](<2.2-ten-step-algorithm.md>).

## 4. Vertical flux divergence

This section must distinguish two forms: the **conservative flux divergence**
\(-\partial_\sigma(\dot\sigma X)\) in the moisture equation, and the **advective form**
\(-\dot\sigma\,\partial_\sigma Q\) in the temperature and wind equations. They are related by the product rule, but they are not the same operator:

$$
-\frac{\partial(\dot\sigma X)}{\partial\sigma}
=-\dot\sigma\frac{\partial X}{\partial\sigma}
-X\frac{\partial\dot\sigma}{\partial\sigma}.
\tag{2.4.7}
$$


### 4.1 Flux differences from control-volume integration

First consider a conserved scalar satisfying

$$
\frac{\partial X}{\partial\tau}
+\frac{\partial F^\sigma}{\partial\sigma}=0,
\qquad
F^\sigma=\dot\sigma X
\tag{2.4.8}
$$

and integrate over layer \(k\), \([\sigma_{k-1/2},\sigma_{k+1/2}]\):

$$
\frac{d}{d\tau}
\int_{\sigma_{k-1/2}}^{\sigma_{k+1/2}}X\,d\sigma
=-
\int_{\sigma_{k-1/2}}^{\sigma_{k+1/2}}
\frac{\partial F^\sigma}{\partial\sigma}\,d\sigma
=-\left(F^\sigma_{k+1/2}-F^\sigma_{k-1/2}\right).
$$

If \(X_k\) denotes the layer average, then
\(\int X\,d\sigma\approx X_k\Delta\sigma_k\), and hence

$$
\left.\frac{\partial X_k}{\partial\tau}\right|_{\mathrm{vert}}
=-\frac{F^\sigma_{k+1/2}-F^\sigma_{k-1/2}}
{\Delta\sigma_k}.
\tag{2.4.9}
$$

Since σ increases from 0 at the model top to 1 at the surface, \(F^\sigma>0\) means downward transport. The signs in (2.4.9) can be read as follows: a positive bottom-interface flux \(F_{k+1/2}^\sigma\) carries material out of layer \(k\), so it enters with a minus sign; a positive top-interface flux \(F_{k-1/2}^\sigma\) carries material into the layer, so it enters with a plus sign.

### 4.2 Where the interface value of a scalar comes from

\(\dot\sigma\) already sits on the interfaces, but \(X\) is stored at full-level centers, so \(X_{k+1/2}\) must still be constructed. PlaSiC uses the symmetric average of the two adjacent layers (Simmons & Burridge, 1981)

$$
X_{k+1/2}\approx\frac{X_k+X_{k+1}}{2},
\qquad
F^\sigma_{k+1/2}
\approx\frac12\dot\sigma_{k+1/2}(X_k+X_{k+1}).
\tag{2.4.10}
$$

Substituting (2.4.10) into (2.4.9), the conservative vertical tendency of an interior layer is

$$
\begin{aligned}
\left.\frac{\partial X_k}{\partial\tau}\right|_{\mathrm{vert}}
\approx-\frac{1}{2\Delta\sigma_k}
\Big[&\dot\sigma_{k+1/2}(X_k+X_{k+1})\\
&-\dot\sigma_{k-1/2}(X_{k-1}+X_k)\Big].
\end{aligned}
\tag{2.4.11}
$$

This is why the moisture code stores the sum of the two adjacent layers as an interface temporary. The implementation first stores

$$
H_{k+1/2}
=\dot\sigma_{k+1/2}(X_k+X_{k+1}),
$$

and then multiplies by the precomputed

$$
\mathtt{reciprocal\_double\_sigma}[k-1]
=\frac{0.5}{\Delta\sigma_k}
=\frac{1}{2\Delta\sigma_k}.
\tag{2.4.12}
$$

### 4.3 Why the top, interior, and bottom layers are treated separately

The top and bottom boundaries satisfy the no-penetration conditions

$$
\dot\sigma_{1/2}=\dot\sigma_{L+1/2}=0,
\qquad
F^\sigma_{1/2}=F^\sigma_{L+1/2}=0.
\tag{2.4.13}
$$

The conservative vertical tendency therefore takes three different forms:

$$
\begin{aligned}
\text{top layer }k=1:\quad
-\frac{F^\sigma_{3/2}}{\Delta\sigma_1},\\[3pt]
\text{interior layer }1<k<L:\quad
-\frac{F^\sigma_{k+1/2}-F^\sigma_{k-1/2}}
{\Delta\sigma_k},\\[3pt]
\text{bottom layer }k=L:\quad
+\frac{F^\sigma_{L-1/2}}{\Delta\sigma_L}.
\end{aligned}
\tag{2.4.14}
$$

### 4.4 Why temperature and wind use adjacent-layer differences { #vertical-advection-layer-difference }

The primitive equations for temperature and horizontal wind contain the advection term
\(-\dot\sigma\,\partial_\sigma Q\). For the Robert wind one can take \(Q=U,V\) directly; for temperature one first splits \(T=T_0+T'\), applies the same discretization to \(T'\), and adds the inter-layer differences of the fixed reference profile \(T_0\) separately. At an interior interface \(k+1/2\), the jump between the two adjacent full layers is formed first:

$$
\Delta_{k+1/2}Q=Q_{k+1}-Q_k.
$$

PlaSiC combines the contributions of the two bounding interfaces symmetrically, weighted by the target-layer thickness \(\Delta\sigma_k\):

$$
\begin{aligned}
\left(
\dot\sigma\frac{\partial Q}{\partial\sigma}
\right)_k
\approx\frac{1}{2\Delta\sigma_k}
\Big[&\dot\sigma_{k+1/2}(Q_{k+1}-Q_k)\\
&+\dot\sigma_{k-1/2}(Q_k-Q_{k-1})\Big].
\end{aligned}
\tag{2.4.15}
$$

The code therefore stores, at every interior interface,

$$
J^Q_{k+1/2}
=\dot\sigma_{k+1/2}(Q_{k+1}-Q_k),
\qquad Q\in\{T',U,V\},
\tag{2.4.16}
$$

and an interior layer then **adds** its two \(J^Q\) values and multiplies by \(1/(2\Delta\sigma_k)\). The top layer keeps only the term from the interface below it, and the bottom layer keeps only the term from the interface above it. Because the right-hand side of the prognostic equations carries a minus sign, the final tendency is minus (2.4.15).

The reference-profile contribution of temperature is added separately, with the same interface structure, through       \(\Delta T_{0,k+1/2}=T_{0,k+1}-T_{0,k}\); so the fact that `temperature_vertical` in the source uses only \(T'\) differences does not mean that \(T_0\) is ignored. Its divergence-linear part is not evaluated at the grid-point stage, however: it is assembled into the matrix \(\Gamma\) and restored by the semi-implicit solve of [2.5 Semi-Implicit Gravity-Wave Solve](<2.5-semi-implicit-gravity-wave-solver.md>); only the part driven by \(\mathbf v_h\!\cdot\!\nabla_h\pi\) stays in the grid-point source. The same split applies to the \(\kappa T_0\omega/p\) term, and \(DT'\) is always explicit.

"Sum for moisture, differences for temperature and wind" can now be stated precisely:

| Variable type | Continuous form | Interface temporary | In-layer combination |
|---|---|---|---|
| Mass-weighted humidity \(\chi\) | \(-\partial_\sigma(\dot\sigma\chi)\) | \(\dot\sigma(\chi_k+\chi_{k+1})\) | subtract the top flux from the bottom flux, then negate |
| Temperature perturbation and Robert wind \(Q\in\{T',U,V\}\) | \(-\dot\sigma\,\partial_\sigma Q\) | \(\dot\sigma(Q_{k+1}-Q_k)\) | add the bottom and top terms, then negate; temperature adds the reference-profile contribution separately |
